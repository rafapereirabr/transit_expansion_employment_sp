# Session and handoff rule

Use `quality_reports/session_logs/YYYY-MM-DD_description.md` when work spans sessions or includes a
meaningful design decision. Record the objective, decisions and rejected alternatives, files or
targets touched, verification results, blockers, and next action.

Git records what changed; the session log records why. Do not duplicate a full diff or store
restricted data, identifiers, secrets, or machine-specific paths in a log.
